# Escape the Locker Room

A single-page, football-themed "escape room" puzzle game. Work through a series of
puzzles against the clock to escape the locker room and get out onto the pitch.

The whole game is a single self-contained `index.html` — inline CSS and JavaScript
with embedded images, no build step and no dependencies (other than Google Fonts,
loaded at runtime).

## Play

Live site: https://hellboy1975.github.io/aligent-mye-2026/

## Run locally

Open `index.html` in any modern browser, or serve the folder:

```sh
python3 -m http.server
```

then visit http://localhost:8000/.
